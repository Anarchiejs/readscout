# Benchmark

Run it yourself: `readscout bench` (or `readscout bench --models gemma4:e4b,gemma4:12b`). It prints a table to paste
into a [GitHub issue](https://github.com/Anarchiejs/readscout/issues/new?title=bench) and saves the full results as JSON.
Reports from other GPUs are how the model catalog improves.

## Public corpus v1

Four MIT-licensed repositories, downloaded from GitHub at pinned commits and checked against a content fingerprint
(nothing is redistributed). Ground truth is computed from the code, never written by hand.

| Repository | License | What it tests |
|---|---|---|
| [sahat/hackathon-starter](https://github.com/sahat/hackathon-starter) @ `574a993` | MIT | 101 one-line Express routes with auth and rate-limit middlewares; 34 environment variables across 179 KB of controllers; doc-comment needles |
| [hagopj13/node-express-boilerplate](https://github.com/hagopj13/node-express-boilerplate) @ `179ae84` | MIT | routes chained over several lines (`router.route(path).get(...)`), permission middlewares, a Joi config schema |
| [fastapi/full-stack-fastapi-template](https://github.com/fastapi/full-stack-fastapi-template) @ `7257e60` | MIT | Python endpoints whose auth is either in the decorator or implicit in the signature |
| [vercel/nextjs-subscription-payments](https://github.com/vercel/nextjs-subscription-payments) @ `bdd0813` | MIT | Supabase calls where the table and the operation sit on different lines |

Plus 4 synthetic logs (67-750 KB, generated by readscout) and 7 edit tasks on a small project written for readscout,
judged by hidden checks (AST comparison, behaviour tests, mutation testing for written tests).

| Family | Tasks | Difficulty |
|---|---|---|
| routes_list | 2 | list every route or endpoint, including chained and multi-line declarations |
| routes_filter | 5 | routes carrying a given middleware or dependency; returning another route counts against precision |
| routes_negation | 3 | routes **without** a protection: the hardest family for small models |
| data_access | 1 | tables and operations split across lines |
| env_vars | 2 | variables in a 179 KB folder (several chunks) or a schema |
| locate | 8 | "where is the code that does X", X taken from a doc comment |
| log | 4 | root cause hidden in a noisy log |

Score = F1 of the verified findings (recall of the ground truth times precision of what was returned).

| gemma4:12b | 0.98 | 1.00 | 0.88 | 1.00 | 0.65 | 0.88 | 1.00 | **0.91** | 23 | **6/7** | 12 |

| gemma4:e2b | 0.60 | 0.76 | 0.12 | 0.82 | 0.71 | 1.00 | 1.00 | **0.72** | 3 | **4/7** | 3 |

Full data: [bench-results/rtx4060ti-8gb_32gb-ram_windows.json](bench-results/rtx4060ti-8gb_32gb-ram_windows.json).

What it shows:
- Small models are as good as big ones at extraction (route lists, filters, logs) but fall apart on **negative
  questions** (0.48 and 0.12). readscout therefore sends negative questions to the quality model automatically.
- `gemma4:12b` matches `gemma4:26b` at reading; it is the better quality model for 10-12 GB GPUs or 16 GB of RAM.
- The public corpus found a real bug: identical quoted lines (the same decorator on several endpoints) were all
  located at their first occurrence. Fixed in 0.1.0 (the model's line hint now picks among verified occurrences);
  scores before the fix were 0.70 (e4b) and 0.84 (26b).

## Appendix: model-selection campaign (private corpus)


Measured on one machine: RTX 4060 Ti 8 GB, Ryzen 5 7600X, 32 GB DDR5, Windows 11, Ollama 0.40 and llama.cpp b11592.
Models at 4-bit quantization, 32k context, 8-bit KV cache, temperature 0.

### Method

**Reading: 41 tasks** generated from two real web projects (an Express API of about 450 files and a React/Supabase
site), with ground truth computed from the code itself, never written by hand. Each task runs through the real
readscout pipeline (chunking, schema-constrained output, quote verification). Score = F1 of the verified findings.

| Family | Task | Tasks |
|---|---|---|
| routes_all | list every HTTP route of a file (13-41 KB) | 11 |
| routes_filter | routes carrying a given middleware (rate limit, consent, admin) | 9 |
| routes_noauth | routes **without** authentication (negation) | 3 |
| supabase | tables accessed by a file and the operation | 4 |
| env_dir | environment variables read in a whole folder (99-427 KB, several chunks) | 2 |
| locate | "where is the code that does X", X taken from a comment block, in 25-33 KB files | 9 |
| log | root cause in a noisy log of 67-753 KB | 3 |

**Editing: 7 tasks** on a small Python project, each judged by hidden checks the model never sees: fix a pagination
bug, add docstrings without changing code (AST comparison), rename a function across files, add a parameter, add type
hints, add a method, and write tests (scored by mutation testing: share of 5 mutants killed).

That corpus is private: these numbers chose the model families, the public benchmark above is the reproducible reference.

### Variants that did not help

| Variant | Effect |
|---|---|
| Re-checking each finding with the same model | Gemma 4 E4B 0.80 to 0.75 and twice slower; Gemma 4 26B also lower on negations |
| 12 KB chunks instead of the largest that fits | no change (0.80 vs 0.80) |
| Stronger instruction for negative questions | removes inverted answers seen in real use, one extra finding on one task |
